## 第二步：用 SSH 连接服务器

VPS 不是你本地的电脑，你得用 SSH 工具远程连进去。

工具推荐：

- **Windows 用户**：FinalShell（国产免费，自带 SFTP 文件管理）或 Xshell（经典）
- **Mac / Linux 用户**：直接打开终端，输入 `ssh root@你的VPS_IP` 回车

Windows 举例：

1. 打开 FinalShell，点击「新建连接」→「SSH 连接」
2. 主机地址填 VPS 的 IP，端口默认 22，用户名 `root`，密码填部署完成后收到的密码
3. 点连接，等出现命令提示符 `root@hostname:~#`，就说明连上了

SSH 连上之后，就可以开始安装宝塔了。

## 第三步：执行宝塔面板安装命令

这是最核心的一步，直接复制以下命令，粘贴到 SSH 终端，回车执行：

bash
if [ -f /usr/bin/curl ];then curl -sSO https://download.bt.cn/install/install_panel.sh;else wget -O install_panel.sh https://download.bt.cn/install/install_panel.sh;fi;bash install_panel.sh ed8484bec


这是宝塔官方通用安装脚本，会自动检测你的系统（Debian/Ubuntu/CentOS 均适用）。

执行后，终端会问你：


Do you want to install Bt-Panel to the /www directory now?(y/n)


输入 `y` 回车，然后等待安装完成，大约需要 3～10 分钟。安装完成后，终端会显示类似这样的信息：


==================================================================
Congratulations! Installed successfully!
==================================================================
外网面板地址: http://x.x.x.x:8888/xxxxx
内网面板地址: http://xxx.xxx.x.x:8888/xxxxx
username: xxxxxxxx
password: xxxxxxxx


**一定要把这段信息复制保存下来**，里面有你的初始登录地址、用户名和密码。

## 第四步：开放宝塔所需的端口

安装完成后，先别急着去浏览器打开面板地址。Evoxt VPS 本身是 KVM 虚拟化，没有额外的安全组限制（不像阿里云、腾讯云那样需要在控制台单独配安全组），但你需要确保服务器操作系统本身的防火墙放行了宝塔需要的端口。

宝塔安装完后会自动帮你放行大部分端口，不过保险起见，可以在面板里的「安全」页面手动检查是否放行了以下端口：

| 端口 | 用途 |
|------|------|
| 8888 | 宝塔面板默认访问端口（核心，必须放行） |
| 80 | HTTP 网站访问 |
| 443 | HTTPS / SSL 证书 |
| 22 | SSH 远程连接（可改端口后关闭默认 22） |
| 3306 | MySQL 数据库（建议只对内网开放） |

如果你用的是带 Evoxt 内置防火墙功能的机器，也可以直接在 Evoxt 控制台的 Firewall 页面图形化添加放行规则——几下点击搞定，不用敲命令。

## 第五步：登录宝塔面板，完成初始化

端口确认放行之后，打开浏览器，在地址栏输入安装完成时显示的外网面板地址，格式类似：


http://你的VPS_IP:8888/安全入口路径


输入用户名和密码，登录进去。

第一次登录时，宝塔会弹出提示，让你一键安装 **LNMP 网站环境**（Linux + Nginx + MySQL + PHP）。选择这个套餐，推荐配置：

- **PHP**：7.4 或 8.1（建站首选）
- **MySQL**：5.7 或 8.0
- **Nginx**：最新稳定版
- 其余默认

点一键安装，等十来分钟，Web 服务器环境就全搞好了。接下来就可以在「网站」菜单添加你的域名、上传网站文件，开始跑自己的应用了。

## 常见问题 & 故障排查

**面板地址打不开 / 提示连接拒绝？**

90% 的情况是端口没放行。在 SSH 里执行：

bash
bt default


可以查看当前面板地址、端口、用户名密码。确认端口后，再检查防火墙是否放行了对应端口。

**忘记宝塔登录密码？**

SSH 连接 VPS 后，执行：

bash
bt 5


按提示重置密码即可。

**宝塔面板启动失败？**

执行以下命令手动重启面板：

bash
bt restart


**安装过程中网络中断？**

重新执行安装命令即可，宝塔的安装脚本支持重复执行不会出错。

## 安装完成后，别忘了做这几件安全加固

面板装好了，但别傻乎乎地把默认配置就这么用上线。几个必做的安全设置：

1. **修改面板登录端口**：把默认的 8888 改成一个不常见的高位端口（如 51888），防止被扫描器乱碰
2. **修改安全入口路径**：在「面板设置」里把登录路径从 `/bt` 改成随机字符串
3. **修改初始密码**：改成 16 位以上强密码，大小写字母 + 数字 + 符号
4. **开启二步验证**：绑定手机 OTP 令牌，防止密码泄露后被登录
5. **关闭 SSH 默认 22 端口**：把 SSH 端口改为其他数字，并在面板「安全」里关闭原来的 22

Evoxt 自带的 Firewall 防火墙功能可以图形化操作端口规则，加固过程不需要敲命令，点几下就行——对新手来说非常友好。
